# Trade Policy Lab (AREC 530)

Interactive companion to the AREC 530 lecture notes *Trade Policies: Importing and Exporting Countries*:
tariffs, import quotas, tariff-rate quotas and export subsidies for small and large countries, a
large-country tariff worksheet, and a real-world case on China's 2018 tariff on US soybeans.

Live page: https://deluair.github.io/arec530-trade-policy-lab/

Soybean data: UN Comtrade, HS 1201 (China imports as reported by China; US exports as reported by the US), pulled 29 Oct 2026.
